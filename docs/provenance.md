# Provenance

Every module ported into this repository records where it came from. A selective
port stops receiving fixes from its source, so the commit matters as much as the
repository.

Our own earlier prototypes appear here by role (the meeting-bot prototype, the bwat prototype,
our agent service), with their paths shortened where a name would say what they were. The
exact repository and path behind each row are kept privately alongside this file.
